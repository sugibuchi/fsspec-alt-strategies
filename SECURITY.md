# Security policy

## Supported versions

Fixes go into the latest release only.

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/sugibuchi/fsspec-alt-strategies/security/advisories/new),
not in a public issue.

Include what you can of:

- the version;
- what an attacker can do, and what they need;
- the steps to reproduce it.

You should get an answer within a week. Once a fix is released, the advisory is published, with credit to you unless
you prefer otherwise.
